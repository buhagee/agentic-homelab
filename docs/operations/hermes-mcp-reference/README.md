# Hermes MCP manifest archive

These files are **reference only**. They are not read by
`scripts/deploy/deploy-agent-config.sh`.

The Hermes UI owns live MCP servers, plugins, skills, and OAuth tokens. Use the
dashboard MCP page at `https://hermes.${QACEY_DOMAIN}` or
`https://hermes-annique.${QACEY_DOMAIN}` to add, test, enable, or remove a
server.

Keep this archive for migration and disaster-recovery reference. Do not edit it
expecting a deployment to apply it.
